## Directrices del Proyecto
- **Tecnologías obligatorias:** Java, Servlets, JSP (JavaServer Pages), JDBC y Apache Tomcat.
- **Arquitectura:** Patrón Modelo-Vista-Controlador (MVC) clásico con Servlets como controladores y JSP como vistas.
- **Restricción:** No utilizar frameworks de Node.js, Spring Boot ni motores de plantilla como Thymeleaf. Todo debe resolverse con Java nativo y JSP puro.
